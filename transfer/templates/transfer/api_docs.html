DEVELOPER REFERENCE

Документация API.

Справочник HTTP API Playlist Bridge. Машиночитаемая схема OpenAPI 3.1 доступна отдельно.

Общие правила

  • Базовый префикс версионированного API: /api/v1/.
  • Ответы API имеют формат JSON, если не указано иное.
  • Запросы, изменяющие состояние, используют POST и требуют действующую браузерную сессию и CSRF-токен Django.
  • OAuth-токены провайдеров не передаются клиентом в API-запросах: сервер получает их из зашифрованного хранилища подключённого аккаунта.
  • Не передавайте пароли, access/refresh tokens, client secrets или заголовки Authorization в тикетах, логах и примерах.

API предназначен для работы через интерфейс приложения и браузерную сессию, а не для сторонних серверных интеграций.

Методы

GET /api/v1/status/

Возвращает состояние подключений текущей сессии и конфигурационные флаги. Не возвращает OAuth-токены или секреты.

POST /api/v1/transfers/

Создаёт задачу прямого переноса публичного плейлиста VK в Spotify. Требует подключённый Spotify и CSRF-токен.

Заголовки: Content-Type: application/json, X-CSRFToken: csrf-token.

Тело:

{
  "source_url": "https://vk.ru/music/playlist/241688629_5_example",
  "target_playlist": ""
}

source_url — публичная ссылка на плейлист VK (строка до 2048 символов). target_playlist — необязательный Spotify playlist ID из 22 допустимых символов; пустая строка означает создание нового приватного плейлиста.

Ответ: HTTP 202 и объект job с UUID, статусом и счётчиками прогресса. Повторный запрос при активной задаче возвращает текущую задачу.

GET /api/v1/transfers/{job_id}/

Возвращает статус и прогресс задачи, принадлежащей текущей сессии.

GET /api/v1/transfers/{job_id}/report/

Возвращает JSON-отчёт завершённой задачи. До успешного завершения возвращает HTTP 409.

GET /api/v1/openapi.json

Машиночитаемая OpenAPI 3.1 схема.

GET /healthz/

Проверка работоспособности веб-приложения. Не раскрывает состояние секретов и подключения провайдеров.

Коды ответов

  • 200 — успешное чтение.
  • 202 — задача принята в очередь или уже выполняется.
  • 400 — некорректный JSON или параметры.
  • 401 — Spotify не подключён для текущей сессии.
  • 404 — задача отсутствует или недоступна текущей сессии.
  • 409 — отчёт ещё не готов.
  • 415 — неверный Content-Type.
  • 503 — не настроено шифрование credentials или недоступна очередь задач.
